# 個性心理學® 七夕支局 結業測驗（kosei-quiz）

基礎講座・上級講座の受講生が、講座の最後にQRコードを読み取り、スマホで15問の選択式テストを受ける。
受講日・担当講師・名前を入力してから受験し、満点になるまで再挑戦する。
各回の結果（点数・層別内訳・誤答した問題）は自動で Google スプレッドシートに記録され、満点になると修了画面が出る。

- 完全静的サイト（HTML + CSS + Vanilla JS）。ビルド工程なし
- ホスティング: GitHub Pages（このリポジトリは公開）
- **問題はこのリポジトリに置かない。** Google スプレッドシートの「問題」シートに置き、QRコードのURLに入った講座ごとの鍵が合ったときだけ取得できる
- 通信は自サイトのJSONの読み込みと、Google Apps Script との送受信のみ。外部フォント・アナリティクスなし
- 表示言語: 繁體中文

仕様は `koza-quiz-spec.md` を参照（§10・§11 が追加仕様）。

## しくみ

```
受講生のスマホ ──QRコード（URL に鍵 #k=...）──▶ GitHub Pages（画面だけ）
                                                   │
                                                   ▼ 鍵を付けて問い合わせ
                                     Google Apps Script（松本さんのアカウント）
                                       ├─ 鍵が合えば「問題」シートの問題を返す
                                       └─ 結果を「結果」シートに1行ずつ追加
```

- 基礎のQRコードには基礎の鍵、上級のQRコードには上級の鍵が入っている。基礎のQRコードで上級のテストは開けない
- 鍵のないURL（`.../advanced/` を直接開くなど）では「請掃描講師提供的 QR Code」と表示されるだけ

## スプレッドシートの設定（最初に一度だけ）

Google アカウントへのログインと承認が必要なので、松本さんが操作する。

1. Google ドライブで新しいスプレッドシートを作る（名前は自由。例: 結業測驗）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初からある `function myFunction() {...}` を消し、`gas/Code.gs` の中身をすべて貼り付けて保存（💾）
4. 上の関数の選択欄で **setup** を選び **実行** を押す
   - 承認を求められたら許可する（「このアプリは確認されていません」と出たら「詳細 → 安全ではないページに移動」）
   - スプレッドシートに「設定」「問題」「結果」シートができ、講座ごとの鍵とQRコード用URLが「設定」シートに入る
5. 右上の **デプロイ → 新しいデプロイ** を開き、種類の歯車から **ウェブアプリ** を選ぶ
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
6. **デプロイ** を押し、表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピー
7. `config.json` の `endpoint` にそのURLを貼り付けて push
8. 「問題」シートに問題を入れる（下記）
9. 「設定」シートの **QR Code 用 URL** をQRコードにして使う

## 問題の入れ方・直し方（「問題」シート）

1行に1問。直したら保存するだけで、次に開いたテストから反映される（デプロイし直す必要はない）。

| 列 | 内容 |
|---|---|
| 課程 | `basic` または `advanced` |
| id | 問題の識別子（例: `b01`）。**「結果」シートに記録されるので、一度使ったら変えない・使い回さない** |
| 層 | `說得出` / `分得出` / `用法` |
| 問題 | 問題文 |
| 選項A〜選項D | 選択肢4つ（受講生の画面では毎回並びが変わる） |
| 正解 | `A`〜`D` |
| 誤解選項 | 典型的な誤解の選択肢（`A`〜`D`）。**用法の問題には必ず1つ**、それ以外は空欄でよい |
| 說明 | 誤答したときに出す解説 |
| 補充 | 誤解選項を選んだ人にだけ追加で出す解説（空欄でよい） |

### 「設定」シート

| 列 | 内容 |
|---|---|
| 課程 | `basic` / `advanced`（変えない） |
| 標題 | 開始画面に出るタイトル |
| 版本 | 問題の版。「結果」シートに記録されるので、問題を直したら変える（例: `2026-11`） |
| 說得出・分得出・用法 | 毎回その層から何問出すか（合計15）。3つとも空欄なら、その講座の全問（15問ちょうど）を出す |
| 鍵 | QRコードに入る鍵。setup で自動発行される |
| QR Code 用 URL | この URL をQRコードにする |

### 出題の動き

- 層ごとに指定の数だけランダムに選ぶ（再挑戦のたびに選び直す）
- 出題順・選択肢の並びとも毎回シャッフル
- 満点でなければ誤答の解説と「再挑戰一次」ボタン、満点なら修了画面を表示

### 問題のチェック

テストを開いたときに問題の中身を検査し、誤りがあれば開始画面の代わりにエラー一覧を表示する。問題を直したら、QR Code 用 URL を開いて開始画面が出ることを確かめる。

- 各層に `說得出`・`分得出`・`用法` の指定数以上の問題があり、合計が15か
- `id` が重複していないか
- 選択肢が4つとも入っているか、`正解` が A〜D か
- `層` の書き方が正しいか
- 用法の問題に `誤解選項` が1つあるか、誤解選項が正解になっていないか
- `問題` / `說明` が空でないか

エラー例: `b03: answer ""` → 問題 `b03` の「正解」が空欄。

### 鍵を変えたいとき

QRコードが外部に出回ったときなどは、「設定」シートの鍵を別の文字列（英数字）に書き換え、Apps Script のエディタで **refreshQrUrls** を実行する。新しい QR Code 用 URL でQRコードを作り直す（古いQRコードは使えなくなる）。

## 「結果」シート

1回の受験ごとに1行増える。

| 列 | 内容 |
|---|---|
| 受信日時 | 結果が届いた日時 |
| 課程 / 上課日期 / 授課講師 / 姓名 | 開始画面で入力された内容（講師名も手入力なので、集計前に表記ゆれを揃える） |
| 回数 | その人の何回目の挑戦か（同じセッションID内） |
| 得点 / 問題数 / 満点 | 例: 12 / 15 / FALSE |
| 說得出 / 分得出 / 用法 | 層ごとの正答数（例: 4/5） |
| 誤答した問題 / 出題した問題 | 問題の `id`（カンマ区切り） |
| セッションID | 1人の受験（開始〜修了）をまとめる番号。ページを再読み込みすると変わる |
| 問題版 | 「設定」シートの版本 |

## Apps Script を直したとき

`gas/Code.gs` を変更したら、エディタに貼り直して保存し、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン: 新バージョン → デプロイ** で更新する（URLは変わらない）。

## ローカルでの確認方法

```bash
cd kosei-quiz
python3 -m http.server 8000
```

`config.json` に Apps Script のURLが入っていれば、`http://localhost:8000/basic/#k=<基礎の鍵>` で本番と同じ問題が出る。
